# Подключение Google Sheets к боту (для Nazir)

Эта инструкция — чтобы Nazir сам создал таблицу и доступ к ней на своём Google-аккаунте.
Разработчик (Кирилл) ничего из своего аккаунта не использует — все ключи и таблица целиком принадлежат Nazir.

## Шаг 1. Создать таблицу

1. Зайди на https://sheets.google.com (под своим Google-аккаунтом).
2. Нажми «Пустой файл» (большой плюс / «Blank spreadsheet»).
3. Назови таблицу, например «Recipe Bot — Платежи».
4. Скопируй ID таблицы из адресной строки браузера — это длинная строка между `/d/` и `/edit`:
   `https://docs.google.com/spreadsheets/d/ЭТОТ_КУСОК_ID/edit`
   Сохрани его — это `GOOGLE_SHEET_ID`.

Листы «Платежи» и «Дашборд» бот создаст сам при первом запуске — руками ничего добавлять не нужно.

## Шаг 2. Создать проект в Google Cloud (если ещё нет)

1. Зайди на https://console.cloud.google.com (тот же Google-аккаунт).
2. Вверху слева нажми на выпадающий список проектов → «New Project» («Новый проект»).
3. Название — любое, например «recipe-bot-sheets». Нажми «Create».
4. Подожди 10–20 секунд, пока проект создастся, затем выбери его в том же выпадающем списке.

## Шаг 3. Включить Google Sheets API

1. В строке поиска сверху (значок лупы) введи «Google Sheets API».
2. Открой найденный результат → нажми синюю кнопку «Enable» («Включить»).

## Шаг 4. Создать Service Account

1. В строке поиска введи «Service Accounts» и открой раздел «IAM & Admin → Service Accounts».
2. Нажми «+ Create Service Account» сверху.
3. Имя — любое, например «recipe-bot-sheets». Нажми «Create and Continue».
4. Роль можно не назначать (пропусти шаг «Grant this service account access» — нажми «Continue»).
5. На последнем шаге нажми «Done».

## Шаг 5. Создать ключ (JSON) для Service Account

1. В списке Service Accounts найди только что созданный аккаунт, нажми на него.
2. Вкладка «Keys» → «Add Key» → «Create new key».
3. Выбери тип «JSON» → «Create».
4. Скачается файл `.json` — открой его в блокноте, скопируй ВЕСЬ текст целиком (от `{` до `}`).
   Это значение переменной `GOOGLE_SERVICE_ACCOUNT_JSON`.

⚠️ Никому не пересылай этот файл и не публикуй его — это ключ доступа к таблице.

## Шаг 6. Расшарить таблицу на Service Account

1. В скачанном JSON-файле найди поле `client_email` — это адрес вида
   `recipe-bot-sheets@ваш-проект.iam.gserviceaccount.com`.
2. Открой свою таблицу (Шаг 1) → кнопка «Share» / «Настройки доступа» (правый верхний угол).
3. Вставь этот email в поле приглашения, дай роль «Editor» / «Редактор».
4. Нажми «Send» / «Отправить» (можно снять галочку «уведомить по почте» — email не настоящий, письма не дойдут).

## Шаг 7. Прописать переменные в Railway

В Railway → твой проект → вкладка Variables → добавь две переменные:

- `GOOGLE_SERVICE_ACCOUNT_JSON` — весь JSON из Шага 5, вставленный одной строкой
- `GOOGLE_SHEET_ID` — ID таблицы из Шага 1

После сохранения Railway сам перезапустит бота. В логах должна появиться строка
«Google Sheets интеграция включена». Если её нет — значит одна из переменных не задана
или JSON вставлен с ошибкой (проверь, что скопировал файл целиком, без потери символов).

## Что дальше

- Лист «Платежи» — новая строка появляется при каждой успешной оплате (реальной или тестовой через `/testpay`).
- Лист «Дашборд» — считает подписчиков (активные/пробные/истёкшие) и выручку/чистую прибыль
  (за сегодня/за месяц/всего), обновляется каждые 5 минут автоматически.
- Если что-то в Sheets не работает — бот всё равно продолжает принимать платежи и открывать доступ,
  Sheets — необязательная надстройка, а не критическая часть.
